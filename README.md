# بوت إشارات HAKIM_FX (مجاني 100%)

بوت بيعمل نفس منطق مؤشر HAKIM_FX بالظبط (نفس قواعد المناطق والدخول والستوب والهدف، على الشموع المقفولة بس عشان مفيش إعادة رسم)، ويبعتلك كل إشارة جديدة على قناة تليجرام: الزوج، الفريم، الاتجاه، Entry / SL / TP. بيشتغل لوحده على GitHub Actions مجانًا.

## هتحتاج (كلها مجانية):
1. حساب GitHub
2. حساب OANDA Practice (ديمو، فلوس وهمية، بيديك بيانات أسعار لحظية مجانًا)
3. بوت تليجرام + قناة

---

## الخطوة 1: بوت تليجرام والقناة

1. افتح تليجرام ودوّر على **@BotFather**
2. ابعت `/newbot` واختار اسم ويوزر نيم بينتهي بـ bot
3. هيجيلك **التوكن** (كود طويل). احفظه عندك، ده سرّي.
4. اعمل **قناة** جديدة (مثلًا HAKIM_FX Signals)
5. ضيف البوت في القناة **كأدمن** بصلاحية نشر الرسايل
6. ابعت أي رسالة في القناة، وبعدين افتح اللينك ده في المتصفح (حط التوكن مكان الكلمة):
   `https://api.telegram.org/bot<التوكن>/getUpdates`
7. دوّر على `"chat":{"id":-100...` — الرقم اللي بيبدأ بـ `-100` ده **chat_id** بتاع القناة. احفظه.

## الخطوة 2: حساب OANDA Practice (مصدر الأسعار المجاني)

1. ادخل على oanda.com واعمل حساب **fxTrade Practice** (ديمو بفلوس وهمية، مفيش أي إيداع)
2. بعد تسجيل الدخول دوّر على **Manage API Access** أو **OANDA API** في إعدادات الحساب
3. اعمل **Generate** للـ API token واحفظه عندك (سرّي برضه)

## الخطوة 3: رفع البوت على GitHub

1. اعمل حساب GitHub لو ماعندكش (github.com، مجاني)
2. اعمل Repository **جديد وPublic** (اسمه مثلًا hakim-fx-bot)
3. ارفع الملفات (Add file → Upload files)، لازم الشكل يبقى كده:
   - `bot.py`
   - `README.md`
   - `.github/workflows/signals.yml` (اعمله بـ Create new file واكتب الاسم بالمسار ده)
4. روح **Settings → Secrets and variables → Actions → New repository secret** وضيف 3 أسرار:
   - `TELEGRAM_TOKEN` = توكن البوت
   - `TELEGRAM_CHAT_ID` = رقم القناة اللي بيبدأ بـ -100
   - `OANDA_TOKEN` = توكن OANDA
5. روح تاب **Actions** وفعّل الـ workflows لو طلب منك، وبعدين اضغط **Run workflow** أول مرة

## بعد التشغيل

- أول تشغيلة بيعمل معايرة **من غير ما يبعت أي رسايل** (بيعرف الوضع الحالي بس)
- من ثاني تشغيلة، أي إشارة جديدة هتوصلك على القناة في ثواني لدقايق
- البوت بيشتغل كل 5 دقايق (ممكن GitHub يأخر التشغيل دقايق زيادة في الضغط، ده طبيعي)
- لو صفقة ضربت الهدف أو الستوب هيجيلك إشعار بكده كمان
- الفوركس مقفول في الويكند، فمفيش إشارات من جمعة بالليل لحد حد بالليل، ده طبيعي

## تعديل الأزواج أو الفريمات

افتح `bot.py` من على GitHub (علامة القلم) وعدّل قايمة `SYMBOLS` أو `TIMEFRAMES` في أول الملف. الأزواج الموجودة دلوقتي:
EURUSD و GBPUSD و USDJPY و AUDUSD و USDCAD و XAUUSD (الدهب)
والفريمات: 5m و 15m و 1h و 4h

أي تعديل في الملف بيتسجل تلقائيًا والبوت يكمل عليه.

## ملحوظة مهمة

الأسعار بتيجي من OANDA، فممكن تختلف شوية بسيطة عن الأسعار على منصة التداول بتاعتك، وده ممكن يخلي لمس المنطقة يحصل في نقطة مختلفة طفيفة. المنطق نفسه مطابق للمؤشر.
